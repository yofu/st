# 弧長法による幾何学的非線形解析

`arclm.StaticAnalysis` に法線平面型の弧長制御を追加しています。
並進変位と荷重係数を長さの尺度で組み合わせ、極限点の後の荷重下降域も追跡します。
回転自由度は釣合方程式に含めますが、弧長の尺度には含めません。
弾性解析と材料非線形・有限回転の組合せに対応します。材料則は既存の関連流動・完全弾塑性リターンマッピングで、人工的な硬化や軟化は追加しません。複数荷重ケース同時解析、POSTとの併用は拒否します。

GUIでは、抽出済みの荷重ケースに対して次のように実行します。

```text
:analysis -period=L -arc -ds=0.002 -dsmin=0.000001 -dsmax=0.002 -arcscale=0.01 -arcnode=2 -step=100 %<.otl
```

`-step` の先頭は受理する追加ステップ数です。荷重制御用のDELTA・MAXで経路を打ち切りません。
`-ds`、`-dsmin`、`-dsmax`、`-arcscale` はモデルの長さ単位で指定します。
`-arcnode` は曲線出力の変位を監視する節点番号です。省略時の変位欄はゼロです。
既存の幾何学的非線形状態からの継続には `-noinit` を指定します。
継続時は経路方向とステップ番号を引き継ぎ、同じ出力先の `.arc.txt` に追記します。

出力は最終状態、ステップごとの `_ARC_番号` を付けた結果、および荷重係数・変位・残差・弧長拘束誤差・接線剛性の慣性数を含む `.arc.txt` です。
収束失敗時は直前の釣合状態に戻して刻みを縮小し、最小刻み等の制限に達するとエラーで終了します。
停止要求時も最後に収束した状態を保持します。

`cmd/starc` はGUIを再起動せずに実行するための補助CLIです。

```powershell
go run ./cmd/starc -inl model.inl -out arc.otl -steps 100 -ds 0.002 -dsmax 0.002 -loadscale 0.01 -stop-uz 0
```

このCLIは元の検証モデル向けに監視節点61を使用します。任意の監視節点はGUIの `-arcnode` またはGo APIの `ArcLengthOptions.MonitorNode` で指定します。
`-model` はST入力からL荷重ケースを抽出し、`-coordinates` は節点座標JSONを適用します。
`-exact-h200` は検証モデルの断面513を補正する専用オプションです。
これらの専用指定は汎用解析APIの挙動には影響しません。

検証例は `go test -vet=off ./arclm -run TestArcLength -v` で実行できます。
偏平2部材アーチの理論荷重曲線・極大極小点、残差、失敗時の復元、停止、継続解析とWorker状態の保存復元を確認します。


## Arclm101の材料非線形弧長制御

```text
:arclm101 -period=X -init -arc -ds=0.002 -dsmin=0.000001 -dsmax=0.002 -arcscale=0.01 -arcnode=110 -nlap=100 result.otx
```

`-arc` は幾何学的非線形も有効にします。完全塑性だけでは荷重が一定となる機構でも、幾何学的効果等により下降域が生じる場合はその釣合経路を追跡します。
`-nlap` は荷重係数の上限ではなく追加の受理ステップ数です。DELTA・MAXは弧長経路を打ち切る条件として使用しません。
`-init` を省略すれば既存のArclm101と同様に継続し、最後の保存状態の経路方向・塑性変形・回転・荷重係数を使います。

```text
:arclm101 -arc -ds=0.002 -dsmax=0.002 -arcscale=0.01 -arcnode=110 -nlap=100
```

同じ荷重ケースの最新ステップ（例 `X@100`）を表示して実行します。以前のステップの表示からは継続しません。
Arclm101の結果は従来と同じ `result@番号.otx`、最終状態と `.arc.txt` に保存し、GUIのステップ表示と `summary.txt` も引き継ぎます。
`:analysis -arc -nlmat` からも同じ材料非線形の経路を追跡できます（この入口のステップファイルは `_ARC_番号` 形式）。
部材荷重（CMQ）の荷重係数微分と、降伏境界の変位・荷重方向による載荷／除荷判定を含めて連立方程式を解きます。
収束前の試行では塑性状態を確定せず、失敗や停止では直前の収束状態を保持します。

小変位の材料非線形解析で既に塑性化した保存状態には共回転の履歴がないため、その状態からの直接切替は拒否します。
その場合は弾性の初期荷重状態から `-arc` または `-nlgeom` を使って材料非線形解析をやり直してください。
完全な機構や分岐によって拡大方程式自体が特異になる場合は、刻みの縮小でも追跡できずエラーとなる場合があります。

材料非線形の検証は `go test -vet=off ./arclm -run TestMaterialArc -v` で実行できます。
2部材アーチの材料崩壊と下降域の閉形式解、3ヒンジ梁の理論崩壊荷重、残差、除荷、CMQの有限差分、塑性状態の保存復元とWorker経由の継続を確認します。
