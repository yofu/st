# 弧長法による幾何学的非線形解析

`arclm.StaticAnalysis` に法線平面型の弧長制御を追加しています。
並進変位と荷重係数を長さの尺度で組み合わせ、極限点の後の荷重下降域も追跡します。
回転自由度は釣合方程式に含めますが、弧長の尺度には含めません。
現時点では弾性・有限回転の解析が対象で、`-nlmat`、複数荷重ケース同時解析、POSTとの併用は拒否します。

GUIでは、抽出済みの荷重ケースに対して次のように実行します。

```text
:analysis -period=L -arc -ds=0.002 -dsmin=0.000001 -dsmax=0.002 -arcscale=0.01 -arcnode=2 -step=100 %<.otl
```

`-step` の先頭は受理する追加ステップ数です。荷重制御用のDELTA・MAXで経路を打ち切りません。
`-ds`、`-dsmin`、`-dsmax`、`-arcscale` はモデルの長さ単位で指定します。
`-arcnode` は曲線出力の変位を監視する節点番号です。省略時の変位欄はゼロです。
既存の幾何学的非線形状態からの継続には `-noinit` を指定します。
継続時は経路方向とステップ番号を引き継ぎ、同じ出力先の `.arc.txt` に追記します。

出力は最終状態、ステップごとの `_ARC_番号` を付けた結果、および荷重係数・変位・残差・弧長拘束誤差・接線剛性の慣性数を含む `.arc.txt` です。
収束失敗時は直前の釣合状態に戻して刻みを縮小し、最小刻み等の制限に達するとエラーで終了します。
停止要求時も最後に収束した状態を保持します。

`cmd/starc` はGUIを再起動せずに実行するための補助CLIです。

```powershell
go run ./cmd/starc -inl model.inl -out arc.otl -steps 100 -ds 0.002 -dsmax 0.002 -loadscale 0.01 -stop-uz 0
```

このCLIは元の検証モデル向けに監視節点61を使用します。任意の監視節点はGUIの `-arcnode` またはGo APIの `ArcLengthOptions.MonitorNode` で指定します。
`-model` はST入力からL荷重ケースを抽出し、`-coordinates` は節点座標JSONを適用します。
`-exact-h200` は検証モデルの断面513を補正する専用オプションです。
これらの専用指定は汎用解析APIの挙動には影響しません。

検証例は `go test -vet=off ./arclm -run TestArcLength -v` で実行できます。
偏平2部材アーチの理論荷重曲線・極大極小点、残差、失敗時の復元、停止、継続解析とWorker状態の保存復元を確認します。
