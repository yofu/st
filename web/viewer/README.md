# st iPad向けWebエディタ

Gio版と共通の描画・編集・解析処理をWebAssemblyで実行します。モデル、関連ファイル、解析結果はiPadのブラウザ内で扱います。配信用PCにモデルファイルは送信されません。

## iPadで起動

1. Windows PCで旧版の配信サーバーを停止します。新版のZIPを展開し、中の `st-viewer-server.exe` を起動します。実行ファイルと `index.html`、`stio.wasm`、`analysis.wasm`、`analysis-worker.js` などは同じフォルダに置いてください。
2. iPadのSafariで、サーバーの画面に `LAN:` として表示されたアドレスを開きます。以前と同じアドレスを使う場合はページを再読み込みします。
3. 「INPを開く」から、iPadの「ファイル」にある `.inp` を選びます。画面上部にモデル名と節点・部材数が表示されます。

8080番を使用中なら、PowerShellから `./st-viewer-server.exe -listen :8081` で起動できます。終了するにはPCの配信ウィンドウで Ctrl+C を押します。

## モデルを編集

1本指で回転、2本指で拡縮・移動します。「部材」または「節点」に切り替えてからタップすると対象を選択できます。「全体表示」と「選択解除」は画面上部にあります。

画面下部の「コマンド一覧」から選ぶか、コマンドを入力して「実行」を押します。対象の選び方はコマンドによって異なります。例えば `MOVENODE` や `SCALE` では編集対象を先に選び、実行後は履歴の案内に従って基準点などを指定します。「確定」はGio版の右クリックに相当し、「中止」はEscに相当します。「操作キー」から対話中に必要なキーを送れます。

| 操作 | コマンドと手順 |
|---|---|
| 節点を追加 | `:addnode X Y Z` に座標を指定 |
| 線材を追加 | `ADDLINEELEM` を実行し、2節点をタップ |
| 部材を削除 | `ERASE` を実行し、部材をタップして「確定」。部材から参照されない節点も削除 |
| 支持条件を変更 | 節点を選択して `:conf 111000` を実行。6桁はX・Y・Zの並進、X・Y・Zの回転の順で、1が拘束 |
| 線材の端部条件を変更 | 線材を選択して `:bond pin` または `:bond rigid` を実行 |
| 編集を元に戻す／やり直す | `UNDO`／`REDO` |

「コマンド・操作履歴」を開くと、入力と操作案内を表示できます。↑／↓で過去のコマンドを呼び出せます。入力履歴は直近100件を同じブラウザとアドレスで保持します。

## exモード

先頭に `:` を付けて入力します。先頭の `;` は `:` に置き換わります。Gio版で定義されている省略形、コマンド名の末尾に付ける `?`（使い方）、`|` でつなぐパイプ、`:.`（前回のexコマンドを再実行）を利用できます。元に戻す操作は従来どおり `UNDO` です。

| 入力例 | 操作 |
|---|---|
| `:node 101,102` | 節点番号で選択 |
| `:elem sect 101 \| :count` | 断面101の部材を選び、選択数を履歴に表示 |
| `:node 101 \| :move 0.1 0 0` | 節点101をX方向へ0.1移動 |
| `:elem 1001 \| :bond pin` | 部材1001の両端をピンに変更 |
| `:set -sect=102` | 選択部材の断面を変更 |
| `:view top` | 平面表示に切り替え |
| `:e` | ファイル選択画面を開く |
| `:w 編集済み.inp` | モデル全体を書き出し、ダウンロードリンクを表示 |

`:edit` ではファイル選択画面からINPを指定します。`:write` と `:save` は現在のモデル全体をダウンロード用に書き出します。ファイル名を省略すると `元の名前-edited.inp` になります。実行後に「INPをダウンロード」をタップしてください。対応するexコマンドは画面下部の一覧に表示されます。作業フォルダ内のファイルを指定するコマンドは、ファイル名や作業フォルダからの相対パスを指定します。

## 図化モード（Fig2）

先頭に `'` を付けます。無効化できる項目は `'!`、直前の図化コマンドの再実行は `'.` です。例えば `'angle 20 35` で視点を変更、`'nodecode` で節点番号を表示、`'!nodecode` で非表示、`'title 架構モデル` で図上に注記を追加します。`'deformation L` は長期荷重の変形図を表示します。既存の図化設定ファイルを読み込むには、作業フォルダへ追加して `:fig2 model.fig2` を実行します。

## 解析と関連ファイル

「作業フォルダ」→「関連ファイルを追加」で、`.inl`、`.ihx`、`.ihy`、波形CSV、`.fig2` などを取り込みます。解析や出力の完了後は「作業フォルダ」を開き、ファイル名をタップして保存します。

```text
:extractarclm weights.wgt
:analysis -period=L gravity.otl
'deformation L
```

`:extractarclm` は現在のINPモデルから解析用データを作り、指定した名前で重量計算結果を書き出します。作成済みの解析データを使う場合は、例えば `:read model.inl` で読み込めます。材料非線形や時刻歴解析では、必要な材料情報を保持するため、元のINPから抽出してください。

静的解析完了後は、例えば `:arclm101 -period=X -nlap=1 -delta=0.0125 pushover.otx`、`:bclng001 -mode=1 buckling.otp`、`:vibeig -mode=1 vibration.otp` を使えます。時刻歴解析では波形CSVを追加し、静的解析完了後に `:timehistory wave.csv -rayleigh=0.02 -output=response` を実行します。解析ステップや変位の出力、`summary.txt`、各種CSVは作業フォルダからダウンロードします。

計算はiPad上の専用Web Workerで実行します。解析中もモデルを回転・拡縮でき、経過時間、計算ステップ、解析ログを確認できます。座屈や振動固有値解析の探索回数は実行前に確定しないため、経過時間と反復状況を表示します。「解析を停止」または `:stop` で停止できます。停止したジョブの結果や途中の出力は破棄し、直前に完了した結果と継続解析用の状態を保持します。

荷重増分、時刻歴、座屈、振動、断面検定、解析モデルの抽出はそれぞれ単独のコマンドとして実行してください。時刻歴の画面表示には最終ステップを反映し、各ステップの応答はCSVに保存します。大きなモデルでは、解析前のデータ準備や完了時の反映に時間がかかる場合があります。作業フォルダはタブ内の一時保存です。入力は1ファイル32 MiB、作業フォルダ全体は128 MiBまでで、ページの再読込やタブの終了前に必要なファイルをダウンロードしてください。

## ブラウザでのファイル表示と印刷

- `:explorer` は作業フォルダを開きます。`:vim notes.txt` はブラウザでUTF-8テキストを開くか、新規作成します。
- `:hardcopy` はブラウザの印刷画面を開きます。`:fig2print` はFig2設定を読み込み、現在の図をブラウザから印刷します。
- `:copy stress`、`:copy disp`、`:copy amount` の出力は、選択してコピーできるテキスト欄に表示します。
- `:svg`、`:png`、`:pdf` などのファイルは作業フォルダに生成します。PDFで内蔵フォントを使う場合は、日本語文字を描画できないことがあります。

## 編集したINPを保存

1. 対話操作を完了して「INPを保存」をタップします。
2. 表示された「INPをダウンロード」をタップします。編集結果を `元の名前-edited.inp` として、Safariのダウンロード先から確認できます。
3. 同じWeb版やPC版の「INPを開く」で、書き出したファイルを開けます。

元のファイルはそのまま残ります。モデル自体はブラウザに自動保存されません。編集を終えたら、ページを閉じる前にダウンロードしてください。個人設定の `st.pgp` を使う場合は、作業フォルダへ取り込んで `:read pgp st.pgp` を実行します。

## ソースからビルド

リポジトリルートで実行します。`wasm_exec.js` はWasmをビルドしたGoと同じインストールから取得します。

```powershell
.\web\viewer\build.ps1 -OutDir .\dist\stioweb
go build -o .\dist\stioweb\st-viewer-server.exe ./cmd/stiowebserve
```

既存サーバーで配信する場合は、生成された静的ファイルを同じオリジンに配置し、両方の `.wasm` のMIMEタイプを `application/wasm` に設定します。
