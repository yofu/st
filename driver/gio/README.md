# Gio版の画面

Gio **v0.10.3** / Go **1.24.0以降**を使用します。リポジトリのルートでビルドしてください。

```powershell
go build -ldflags="-H windowsgui" -o stio.exe ./cmd/stio
.\stio.exe "C:\path\model.inp"
```

引数なしでは空のモデルで起動します。指定ファイルを開けなかった場合は画面内の履歴にエラーを表示します。

## 画面構成

- 上部: File / Edit / View / Show / Dialog / Command / Tool / Help のメニュー。
- 中央: モデルの描画領域。
- 右側: View / Show / Property の設定タブ。長い設定一覧はスクロールできます。
- 下部: スクロール・選択・コピー可能な履歴、コマンド入力、解析進捗。

### メニュー

File は新規・開く・DXF読込み・挿入・再読込み・保存・名前を付けて保存・結果読込み・Read All・終了です。
Windowsでは「開く」「名前を付けて保存」「DXF読込み」「挿入」「結果読込み」にOS標準のファイル選択ダイアログを使います。
現在のモデルのフォルダ（モデル未指定なら作業フォルダ）を初期表示し、種類に応じた拡張子フィルタを設定します。
名前を付けて保存では現在のファイル名を初期表示します。キャンセルするとモデル・保存先を変更しません。
Windows以外ではGio内のパス入力ダイアログを使います。
Save Asでは拡張子省略時に`.inp`を付け、新しい保存先へ切り替えます。上書きは確認します。
Insertは選択節点（未選択なら原点）に回転角0度で挿入します。

Edit はUndo/Redo・選択解除・選択対象削除・履歴クリア、View は全体表示・標準視点、
Show は全表示・選択対象の表示制御・変形図・色モードです。
Dialog は設定タブへの切替、Command はクリックでの距離計測・検査・選択部材の長さ/面積・ARCLM抽出と解析コマンドの入力補助です。
Editには線材・板材追加、節点・部材移動、部材複製、属性複写、クリックによる削除もあります。
解析コマンドの入力補助は入力欄に雛形をセットします。ファイル名等を確認・変更してEnterで実行してください。
Tool は既存の外部ツール、Help は操作説明とバージョン情報を履歴に表示します。

### 右側設定

- View: 透視投影、倍率、視点距離、角度、注視点、画面中心、XYZ表示範囲。
- Show: 色モード、荷重ケース/ステップ、軸・支持条件の表示寸法、変形/応力倍率、
  各表示のON/OFF、節点/部材キャプション、検定比、部材種別・応力成分・断面別の表示。
- Property: 選択数、長さ/面積、先頭の選択部材の断面・種別・構成節点、選択節点の座標を表示。

数値欄はEnterまたはフォーカスが外れたときに反映します。無効な値は反映せず履歴に理由を表示します。
Propertyは参照用です。IUP専用の断面編集等のダイアログは含みません。

### コマンドと履歴

- Enter / Run: `:...`、`'...`、`DISTS`などの共通編集コマンドを実行します。
- ↑ / ↓: history.datから復元した履歴と今回のコマンドを、入力中の接頭辞で絞り込んで呼び戻します（最大100件）。
- Tab: コマンド名・文脈に応じた引数・ファイル名を補完します。複数候補は繰り返して切り替え、Shift+Tabで逆順に戻ります。
- Ctrl+L: コマンド欄にフォーカス。起動時と描画領域クリック後もコマンド欄で入力できます。
- Ctrl+O / Ctrl+S: 開く / 保存。
- Esc: メニュー・ダイアログを閉じ、通常時は入力・ドラッグ状態と節点・部材の選択を解除。対話入力中もコマンド終了後に選択を解除。
- 履歴のCopy: 保持しているログ全体をコピー。Clear: ログのみクリア。コマンド呼び戻し履歴は残ります。

`History()`と`HistoryWriter()`の両方を履歴へ接続しているため解析の途中ログも表示します。
表示用ログは約256 KiB以内に制限し、古い部分を切り捨てます。解析が出力するCSV等はこの制限の対象外です。

### クリックで指定する対話型コマンド

下部の入力欄にコマンド名を入力してEnterで開始します。先頭の`:`は不要です。
Edit / Commandメニューからも代表的な操作を開始できます。
IUP版と同じ共通コマンド処理（`stlib/st_command.go`）へ、節点・部材・軸、
クリック、キーの押下/解放、ホイール入力を渡します。

| コマンド | 操作例 |
| --- | --- |
| `FENCE` | 左ドラッグ線と交差する部材を選択。Shiftで除外、Ctrlで水平線。 |
| `INTERSECT` | 2部材を左クリックで選択し、右クリックで交点分割。事前選択が2部材以上なら即実行。 |
| `DISTS` | 2節点を左クリックし、座標差と距離を履歴に表示。 |
| `ADDLINEELEM` | 2節点を左クリックして線材を追加。 |
| `ADDPLATEELEM` | 構成節点を順番に左クリックし、右クリックで板材を追加。 |
| `ERASE` | 部材を左クリックして集め、右クリックで削除。事前選択があれば直ちに削除。 |
| `MOVENODE` / `MOVEELEM` / `COPYELEM` | 対象を事前選択し、移動元・先の基準節点を左クリック。 |
| `MATCHPROPERTY` / `COPYBOND` | 複写元部材、複写先部材を左クリック。右クリックで終了。 |
| `TRIM` / `EXTEND` | 基準部材、対象部材を左クリック。右クリックで終了。 |
| `OFFSET` | 元部材をクリックし、Vで距離を選びホイール/J/Kで調整、作成する側をクリック。 |
| `TOGGLEBOND` | 事前選択した線材の端部節点をクリックして端部条件を切替。 |

`ADDARC`、`ADDPLATEELEMBYLINE`、`HATCHPLATEELEM`、`JOINLINEELEM`、`MIRROR`、
`DIVIDEATPLANE`、`ARRAYPOLAR`、`MOVEUPDOWN`、`SPLINE`、`NOTICE1459`、`EDITPLATEELEM`も共通処理へ接続しています。
各コマンド固有の対象条件・処理内容はIUP版と共通です。IUPドライバ内だけにあるコマンドの全移植は対象外です。

指定済み節点からカーソルまで青い仮線を表示します。対話入力中も中ボタンによる視点操作ができます。
キーによる数値指定を使う移動では、X/Y/Zで方向、ホイールまたはJ/Kで増減、
H/Aで刻み10倍、L/Sで刻み1/10、Cでゼロ、Enterで適用します。移動量はmmです。
コマンドがホイール入力を要求している間は、ホイールを数値変更に使います。

Escで入力待ちを終了し、新しいコマンドの実行やモデルを開く操作でも前の入力待ちを終了します。
右クリックの意味はコマンドにより確定または終了です。Escはすでに適用した編集全体を巻き戻す操作ではありません。
Undoは各共通コマンドが保存したスナップショットを戻します。
対話入力の開始時は描画領域へキー入力を移し、終了時はコマンド欄へ戻します。
別のコマンドを入力する場合はCtrl+Lで入力欄へ移れます。

入力待ちの間はモデルのロックを解放し、指定ごとの処理と描画を排他制御します。
入力ルータによる自動テストで距離、追加、削除、移動、属性複写、オフセット、端部条件、
仮線の座標、キー・ホイール、連続クリック、取消・コマンド切替を検証します。
登録済み共通コマンドすべてについて、開始・入力待ちのロック解放・Esc終了も確認します。

## マウス

- 中ドラッグ: 回転。Shift+中ドラッグ: 移動。中ダブルクリック: 角度を保って全体を画面中央に表示。
- ホイール: カーソル位置を中心に拡縮。Ctrl+ホイール: 画面中心を動かさず拡縮。
- 左クリック: 部材選択。Ctrl+左クリック: チェーンを選択。
- 左から右への範囲選択: 全節点が枠内の部材。右から左: いずれかの節点が枠内の部材。
- Alt+左クリック/ドラッグ: 節点選択。IUPと同様に通常は選択を追加し、Shift併用で選択から除外。
- 左ダブルクリック: 選択線材の端部条件切替／選択板材の節点入替。続けて対象節点をクリックし、右クリック/Escで終了。
- 右ボタン解放: コマンド入力があれば実行。空欄の短いクリックは直前の編集コマンドを再実行、Shift併用は直前のExコマンドを再実行。
- 右ボタンを0.2秒以上押して解放: コンテキストメニュー（Gioで対応済みの操作項目）。
- Alt+中ドラッグ: モデルを動かさず範囲ボックスを操作。Shift併用で移動。Alt+ホイールでその倍率を変更。
- 空のモデルでは左ダブルクリックで開くダイアログ、中クリックで最近のモデル一覧。
- 選択部材は橙色の太線で強調します。IUP/CDの点線・ハッチと同一の描画ではありません。

ドラッグ開始時に開始座標と移動差分用の座標を初期化し、操作中のポインタを捕捉します。
描画領域外へ移動しても、ボタンを離すまで同じポインタを追跡します。
コマンド実行中もマウス受信を登録し続け、受信した操作はモデルのロック取得後に順番に反映します。
選択枠はメニューの高さを除いた描画領域内の座標で扱い、Releaseの位置も終点に反映します。
IUP版の画面側の選択枠に合わせ、赤い枠線はモデルキャッシュと分けて毎フレーム重ね描きします。
モデル処理中も枠が追従し、選択ドラッグだけではモデル全体を再描画しません。右から左への枠は破線です。
マウス受信はウィンドウ座標で登録し、描画領域の原点を一度だけ差し引きます。
Windowsでは同じウィンドウのDPI認識コンテキストで実カーソルをクライアント座標に変換し、
最後のドラッグ・解放イベントを補正します。表示倍率を座標へ重複して掛けません。
回転・移動中も通常時と同じ描画処理を使用します。元形状と変形図を重ねた表示も維持します。
`RedrawNode()`も通常の再描画に統一しています。簡略描画を省く分、大規模モデルではドラッグ中の描画負荷が増える可能性があります。
ビューが変化しないフレームでは、従来どおり描画キャッシュを再利用します。
ダブルクリックの時間と許容距離にはWindowsの設定を使います。ドラッグ後のクリックはダブルクリックにしません。
中央表示・Viewメニュー・`:view top/front/...`による視点変更は、Gioのフレームごとにアニメーションします。
IUP版と同様に中心・注視点・角度は線形補間、拡大率は比率で補間し、方位角は短い方向に回転します。
既定の`CanvasAnimateSpeed=0.02`で約0.83秒です。`SetCanvasAnimateSpeed(0.04)`なら約0.42秒、0で即時切替になります。
実行中は`:animatespeed 0.04`でも変更できます（手入力で先頭の`;`を`:`へ置き換える操作も従来どおり）。
ドラッグ・ホイール・Esc・ビュー数値の直接入力で中断し、別の視点変更は現在位置から開始します。
アニメーションのためにコマンドワーカーを待機させません。終端では目標ビューを正確に設定し、再描画要求も停止します。

### 回転・移動速度の変更

共通の初期値は`stlib/st_drawoption.go`の`NewDrawOption()`にあります。
回転は`rotateSpeedX/Y: 0.01`、移動は`moveSpeedX/Y: 0.05`です。
値を2倍にすると同じドラッグ量に対する回転・移動が2倍になります。
回転はドラッグ1ピクセル当たりの度数、移動は画面中心の移動量です。

Gio版だけ変える場合は、`cmd/stio/stio.go`の`stw := stgio.NewWindow(w)`直後に、例えば以下を追加して再ビルドします。

```go
stw.SetCanvasRotateSpeedX(0.02) // 横ドラッグでの回転: 現在の2倍
stw.SetCanvasRotateSpeedY(0.02) // 縦ドラッグでの回転: 現在の2倍
stw.SetCanvasMoveSpeedX(0.10)   // Shift+中ドラッグの横移動: 現在の2倍
stw.SetCanvasMoveSpeedY(0.10)   // Shift+中ドラッグの縦移動: 現在の2倍
```

実際の反映箇所は`driver/gio/st_window.go`の`handlePointer()`です。
今回のファイルダイアログ変更では、速度の初期値は変更していません。

## 実装・検証

UIウィジェットはフレーム処理側で扱い、コマンドは順番にワーカーで実行します。
コマンド実行中・確認待ちは直前のモデル描画を再利用します。
文字入力・ログ更新だけでも再利用するためモデルを毎回描き直しません。
確認ダイアログ待ちでUIのイベント処理を止めません。ログと進捗の更新には排他制御を使っています。
解析エンジンは変更していません。IUP版のFENCE・INTERSECTは、Gio版と同じ共通処理を呼びます。共通対話処理にはGioの排他制御用の任意フックを追加しています。IUP専用コマンドや専用ダイアログの完全な互換実装ではありません。

```powershell
go test ./driver/gio ./cmd/stio -count=1 -v
go test -race -vet=off ./arclm ./matrix ./stlib ./driver/gio ./cmd/stio -count=1
```

入力ルータを通すメニュー・設定・コマンド・履歴・選択、保存先切替・上書き取消、
確認中のUI描画、ログの並行書込み、描画キャッシュを検証します。
WindowsではDirect3Dのオフスクリーン描画で3タブ・メニュー領域・履歴・入力欄も検証します。
GPUを利用できない環境では描画テストのみスキップします。
`stlib`には既存のvet警告があるため回帰テストではvetを無効化しています。

ファイル選択のテストでは選択結果を注入し、実ファイルの読込み、キャンセル、上書き保存、
保存先切替とコマンドからのSaveASを確認します。Windows用の構造体配置、親ウィンドウ、
Unicode、オプションフラグ、標準DLLの関数解決も検証します。
OS標準ダイアログを実際にクリックする手動確認はこの自動テストには含みません。


## IUP版のコマンド入力・履歴との互換動作

- 空欄で`;`を入力すると`:`、空欄で`:`を入力すると`;`になります。2文字目以降の記号は置換しません。
- 最初のSpaceでコマンドの略称を展開します。例：`;e ` → `:edit `、`'gf ` → `'gfact `。
  `!`（強制指定）と`?`（使用方法表示）も維持します。
- ↑／Ctrl+Pと↓／Ctrl+Nは、検索開始時に入力されていた接頭辞で履歴を絞り込みます。
  新しい側の履歴を超えると入力中だった文字列へ戻ります。
- Ctrl+[は入力欄をクリアします。
- Ctrl+I: 挿入、Ctrl+M: 再読込み、Ctrl+R: Read All。
- コマンド欄内のCtrl+A: 全表示、Ctrl+E: 入力モデルを関連付けアプリで開く、Ctrl+X: 右パネルの断面表示一覧。
  コマンド欄以外のテキスト欄では通常の選択・コピー操作を使えます。
- 編集イベントとEnterが同じ描画フレームに届く場合も、置換・略称展開後の文字列を実行します。

起動時に`HOME/.st`から次の2ファイルを読み込みます。HOMEが未設定ならOSのユーザーホームを使います。

| ファイル | 内容 |
| --- | --- |
| history.dat | コマンド履歴。最新を先頭に保存。同じコマンドは最新位置へ移動し、最大100件を保持。 |
| recent.dat | 最近開いたモデル。`#0`が直近、`#1`がその前、`#2`がさらに前。 |

IUP版と同じファイルを使用します。既存のUTF-8・CRLF形式とUTF-8 BOM付きファイルを読み込めます。
コマンドは実行受付時、モデル履歴はモデルを開いた時や保存先を変更した時に保存するため、
ウィンドウを閉じた後の起動でも使えます。履歴フォルダがなければ保存時に作成します。
書込みは同じフォルダの一時ファイルから置換します。既存ファイルを読めなかった場合は上書きせず履歴にエラーを表示します。
画面下部の表示ログ自体はhistory.datには保存しません。

```text
;e #0     （Space入力で :edit #0 となり、Enterで直近のモデルを開く）
:e #0     （貼り付け、履歴呼び戻し、または入力補助で指定する場合）
:e #1     （1つ前のモデル）
:#        （最近のモデルを履歴欄に表示）
```

`#0:h`、`#0<.otl`、`%<.otx`等の既存ファイル名展開も利用できます。
空白・日本語を含むモデルパスの`#0`・`%`展開も修正しています。
検証ではユーザーの実際の履歴ファイルを書き換えず、一時フォルダに履歴・モデルを作って
保存、再起動、`:e #0`／`:e #1`による実ファイル読込み、接頭辞検索、補完、重複排除、100件上限を確認しています。

## st.pgpによるエイリアス

起動時に`HOME/.st/st.pgp`を自動で読み込みます。HOMEが未設定ならOSのユーザーホームを使います。
ファイルがなければ標準コマンドのまま起動します。既存ファイルは書き換えません。

```text
D    DISTS
A    ADDLINEELEM
DD   MOVENODE
CP   :conf 111000
NS   :nodesort _
```

`D`を入力してEnterを押すと距離計測を開始できます。名前の大文字・小文字は区別しません。
共通編集コマンド、`:...`のExコマンド、`'...`のFig2コマンドを登録できます。
`_`を含む定義は、その位置にカーソルを置いた入力欄を開き、追加入力後のEnterで実行します。
Ex定義の`@1`などはIUP版と同様、呼出しごとに1ずつ増える連番になります。
空行・`#`で始まるコメント・空白/タブ区切り・UTF-8 BOM・CRLFに対応します。
重複する名前はファイル内の後の定義を優先します。
IUP専用でGio未対応のコマンド名は登録せず、ファイル名・行番号を履歴に表示します。

変更後は再起動するか、`:read pgp C:/Users/yofu/.st/st.pgp`のように指定して再読込みできます。
手入力時の先頭`;`→`:`の置換も従来どおりです。
再読込み成功時は前のPGP設定を置き換え、読込み失敗時は現在の設定を保持します。
エイリアスは各ウィンドウ内で管理し、共通コマンドの登録表を書き換えません。

## IUP専用コマンドの共通化（第1段階）

`FENCE`と`INTERSECT`を`stlib/st_command.go`へ移植し、共通登録コマンドは26種類になりました。
既存の`st.pgp`の`F FENCE`と`I INTERSECT`も、そのまま使用できます。
Editメニューにも両操作を追加しています。

FENCEは左ドラッグで線を指定し、ボタンを離すと選択して終了します。
通常は選択追加、Shiftで選択から除外、Ctrlで水平線に拘束します。
ドラッグ中は赤い補助線を表示し、Escまたは別コマンドへの切替で取消します。
Releaseだけで終点が変わった場合も反映します。選択のみでモデル形状やUndo履歴は変更しません。

INTERSECTは2部材を事前選択して実行するか、実行後に部材をクリックして右クリックで確定します。
同じ部材を繰り返しクリックしても1部材として扱います。
交点で分割した部材の選択とUndoはIUP版と同じ処理へ集約しています。
交差しない部材・ねじれ位置の部材・線材以外・ロック中の部材は編集しません。
Escは確定前の操作を中止します。

IUP版はマウスコールバック・補助線描画を残し、交点分割と選択判定を共通関数に委譲しています。
IUP版も、次の設定でビルドを確認済みです。

```powershell
$env:CGO_CFLAGS = '-I C:/iup/include'
go build -o st-iup.exe ./cmd/st
```

それ以外のIUP専用コマンド・ダイアログの全面移植は今後の対象です。

## 選択・計測・幾何編集の11コマンド

以下を共通コマンドへ追加し、登録数は37種類になりました。名前を入力してEnter、またはEdit / Commandメニューから開始します。
`st.pgp`の右側に各コマンド名を指定して、短縮名でも利用できます。

| コマンド | 操作 |
| --- | --- |
| `DEFORMEDDISTS` | 2節点をクリック。元形状と変形後の距離・座標差を履歴に表示。表示中の荷重ケースの実変位を使用し、変形表示倍率は掛けません。 |
| `SEARCHELEM` | 節点を事前選択して実行。または実行後に1節点をクリック、あるいは節点番号を入力してEnter。指定節点をすべて含む部材を選択します。 |
| `NODETOELEM` | 構成節点がすべて選択節点に含まれる部材を選択。 |
| `ELEMTONODE` | 選択部材の構成節点を選択。 |
| `MOVETOLINE` | 移動対象の節点を事前選択し、直線を2節点で指定。X/Y/Zで固定する座標を指定（既定X）。 |
| `MOVETOPLANE` | 移動対象の節点を事前選択し、平面を3節点で指定。X/Y/Zで動かす方向を指定（既定Z）。 |
| `MEASURE` | 2節点をクリックし、引き出し方向X/Y/Z/Vを指定。XはY方向寸法、YはX方向寸法、ZとVは2点間距離。Vの引き出し方向は節点間方向とZ軸の外積。文字はmm。 |
| `KIJUN` | 2節点をクリックし、ダイアログで基準線名を入力。名前は小文字へ統一し、重複時は再入力。 |
| `AXISTOCANG` | 線材を事前選択。Sで強軸、Wで弱軸、Tで切替。方向を2節点で指定するか、X/Y/Zキー、Dの座標入力で指定。 |
| `ROTATE` | 対象節点または部材を事前選択。中心節点、回転軸を指定し、ダイアログへ角度[度]を入力。Rを入力すると3参照点による角度指定へ切り替え。 |
| `SCALE` | 対象節点または部材を事前選択。中心節点を指定し、倍率を入力。 |

回転・拡大縮小の中心はDキーで`X,Y,Z`を入力する方法でも指定できます。
方向入力では、Dキーで`X,Y,Z`を入力できます。既に始点を指定している場合は終点座標として扱います。
回転の3参照点は「頂点・始点・終点」の順で指定し、IUP版同様に回転軸に垂直な平面上の0～180度の角度を使います。

入力ダイアログはEnter/OKで確定、Esc/Cancelで取消です。文字列・数値をファイルパスとして加工しません。
不正な数値は履歴に理由を表示して再入力を待ちます。
直線・平面への移動は垂直投影ではなく、上記の固定座標・移動方向を使用します。
ロック・非表示の編集対象は除外します。同じ節点を節点と部材の両方から指定しても1回だけ変換します。
退化した基準形状・部材軸と平行な軸方向等は、編集前に検出して中止します。

形状・部材軸・寸法線・基準線の変更はUndoに対応します。選択と距離計測では変更フラグを立てません。
寸法線のSnapshot対応も追加し、別の編集をUndoしたときも寸法線が失われないようにしました。
寸法線のZ指定で未設定ベクトルを参照する問題を修正し、IUP側も同じ修正を適用しています。

入力ルータと共通入力アダプタを使い、150%表示の座標、方向切替、数値入力、参照回転、
Undo、ロック対象、退化形状、不正数値、ダイアログ取消・コマンド切替をテストしています。
IUP版は`CGO_CFLAGS=-I C:/iup/include`を指定してビルドできます。
